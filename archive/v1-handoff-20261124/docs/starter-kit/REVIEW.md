## Severity-ranked findings

### P1 · Polymatech uses a pre-associate subtotal as FY2025 profit after tax

1. Open `/?company=polymatech&period=FY2025` and select **Profit after tax**. The drawer identifies the source line before the associate contribution. Open `/compare.html` and run the CEO query to see Polymatech at **3.8249×**. For a boundary check, change `Price to earning < 15` to `Price to earning < 3.82` while keeping the other two clauses.
2. The retained consolidated P&L, table index 2, shows ₹37,501.16 lakh before the associate contribution, ₹57.48 lakh from the associate and ₹37,558.64 lakh in the final PAT row dated 31 March 2025. The app displays ₹375.01 crore as PAT. The final row converts to ₹375.5864 crore. The parser's PAT pattern accepts the qualified subtotal, and the normalized record points to row index 15. [Normalized record](../../../../site/data/builds/20261123T190410Z/company/polymatech.json) · [Retained WWIPL financial page](../../../../data/captures/wwipl/20261123T164433Z/polymatech-financial.html) · [Published consolidated statement](https://wwipl.com/unlisted-shares/polymatech-electronics-share-price/financial)
3. With the same ₹36 dealer quote and 398,438,875 shares, the app's P/E calculation gives 3.8249× on the subtotal and 3.8190× on final consolidated PAT. The running 3.82× screen returns zero matches. With final PAT and the same proxy method, Polymatech would match. The retained statement also reports basic EPS of ₹9.07, which gives 3.9691× at the same quote. A 3.90× threshold admits Polymatech under today's app measure and would exclude it using reported basic EPS. The original 15× example passes under all three versions. [Retained share count and quote](../../../../data/captures/wwipl/20261123T164433Z/polymatech-overview.html)

**Correction.** Match final PAT explicitly. Preserve pre-associate profit, owner-attributable profit and reported EPS as separate observations, and keep the existing conflict behavior when two genuinely final PAT rows disagree. Define which P/E measure the screener uses and make its basis visible next to the result. If retaining PAT divided by end-of-period shares, label the result as a calculated proxy and show the distinct reported EPS and its period where available. Rebuild the dashboard, peer inputs and screener, update the report, then rerun the original query and the boundary cases. The acceptance values depend on the chosen and disclosed P/E basis.

### P2 · IGX's quick-ratio drawer omits the issuer evidence for its inventory assumption

1. Open `/`, choose FY2026 and select **Quick ratio**. The drawer shows ₹445.94 crore current assets, ₹294.60 crore current liabilities and inventory of zero. It explains the inventory assumption but links only to the two WWIPL balance-sheet figures. Run the disclosure agent to see the separate link to the issuer's inventory-ratio note on PDF page 54. The supporting balance sheet is on PDF page 5. [FY2026 evidence record](../../../../site/data/builds/20261123T190410Z/company/igx.json) · [Issuer balance sheet](https://testwebcms.igxindia.com/files/financials-5bCIC136dXcpEa1daoEb.pdf#page=5) · [Issuer inventory note](https://testwebcms.igxindia.com/files/financials-5bCIC136dXcpEa1daoEb.pdf#page=54)
2. Select FY2022. The app shows **1.12×** and repeats the same explanation even though the retained restated balance sheet covers FY2024 through FY2026. The application reuses the company-level inventory verdict across all display periods.

**Correction.** Link the inventory note and supporting balance sheet from the same drawer as the ratio. Preserve the distinction between an assumed nil and a reported zero. For periods outside the supporting statement, identify inventory treatment as an inference with its scope, or withhold the quick ratio until period-specific evidence is available. Verify FY2026 and FY2022 on both widths.
