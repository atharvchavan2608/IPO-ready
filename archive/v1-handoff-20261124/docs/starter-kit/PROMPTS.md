# Prompts for building IPO-Ready

Open this repository in your coding agent and paste **Kickoff** into the first build session. Use **Continue** for the next slice or after a design change. For a demo candidate, use **Independent review** in a fresh session, preferably with a different model or reviewer, then send findings to the build agent with **Repair**. Keep new owner feedback in [steering.md](steering.md) so it follows the work across sessions.

## 1. Kickoff

> Read `AGENTS.md` and the linked requirements. Follow the first-session instructions to split the work into tasks, create the to-do list and run log, and complete the first task.

## 2. Continue

> Read `AGENTS.md` and follow the later-session instructions. Resume from the working state and run log, apply the latest steering, and complete and record the next task.

## 3. Independent review

> Act as the founder's independent reviewer. Read `AGENTS.md`, follow its review instructions and write `docs/starter-kit/REVIEW.md`.

## 4. Repair

> Read `AGENTS.md` and `docs/starter-kit/REVIEW.md`. Follow the repair instructions and record the results.
