## Observation

EDGAR filing downloads are free. The reviewed ceiling is ten requests per second; automated requests should declare a user agent. Indexes contain filing identifiers; CIK identifies the filer.

## Interpretation and next use

Discover candidates through filings rather than listed-stock tickers. Retrieve exact filing versions, cache bytes and preserve hashes. A limit is a ceiling, not a throughput target. Configure the team's real contact for continuing acquisition. Public access is not a guarantee against blocking, completeness problems or document-specific reuse restrictions.
