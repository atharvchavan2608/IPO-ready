# X04: XBRL International numeric interpretation guidance

- Type: standards-owner guidance, marked review draft on the page.
- Publisher: XBRL International.
- Checked on: 2026-10-22.
- Source: [iXBRL tagging features](https://www.xbrl.org/guidance/ixbrl-tagging-features/).
- Review depth: scaling, number formats, signs and accuracy sections.

## Observed finding

Inline extraction applies presentation transformations. Scale changes a displayed number into its underlying value; decimals/precision describe accuracy. They are separate mechanisms.

## Interpretation and use

Do not multiply plain XML values by a display-unit factor or treat a negative decimals attribute as a scale instruction. Preserve transformation evidence when processing genuine inline XBRL.

## Limits and next investigation

No Indian filing transformation was validated. Use a conformant processor and a real-instance comparison rather than generalizing from an HTML label.
