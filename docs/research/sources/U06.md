# U06: Executed Reddit access and metadata check

- Type: primary filing-index review and executed API access experiment.
- Publisher: US SEC; issuer Reddit, Inc., CIK 0001713445.
- Source: [S-1 index](https://www.sec.gov/Archives/edgar/data/1713445/000162828024006294/0001628280-24-006294-index.htm), [Submissions JSON](https://data.sec.gov/submissions/CIK0001713445.json), [Company Facts JSON](https://data.sec.gov/api/xbrl/companyfacts/CIK0001713445.json).
- Filing date: 2024-02-22; accepted 15:18:29 as displayed, timezone not established here. API snapshot retrieved: 2026-10-22. API publication/version date is not fixed.
- Depth: real filing index, raw JSON downloads and executed metadata inventory. Full prospectus and financial values not reviewed.

## Observations

All three requests returned HTTP 200 without a key or authentication. Submissions contained 495 recent filing rows, including the original S-1 and three amendments. Company Facts contained 3,331 observations: 889 tagged 10-K, 2,426 tagged 10-Q and 16 tagged DEF 14A. The original S-1 accession was absent.

## Interpretation and limits

This establishes access for one historical issuer and a concrete coverage distinction. Later financial disclosures must not be treated as evidence available at the original IPO. Neither the current fact inventory nor the index proves accuracy, complete initial-filing extraction or broad reliability. Reddit is an access example, not a currently pre-IPO target or a demonstrated research gap.
