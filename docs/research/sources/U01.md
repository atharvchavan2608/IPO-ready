# U01: SEC EDGAR data APIs

- Type/publisher: official API documentation, US SEC.
- Source: [EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces).
- Source dates: page June 6, 2024; last reviewed/updated April 8, 2025. Retrieved/checked: 2026-10-22.
- Review basis: selected documentation and retained native HTML; no API-wide coverage audit.
- Precise locations: `data.sec.gov/submissions/`, “XBRL Data APIs”, `companyfacts/`, “Cross Origin Resource Scripting (CORS)”.

## Observation

Public JSON endpoints require no API key or authentication. Submissions returns filing metadata; Company Facts aggregates supported standard-taxonomy, whole-entity facts. Direct browser CORS is unsupported.

## Interpretation and next use

Use filing history for discovery and inspect actual prospectuses for IPO evidence. API access does not guarantee prospectus-fact completeness. Plan Python retrieval and caching. Endpoint execution and its narrower limits are recorded in U06.
