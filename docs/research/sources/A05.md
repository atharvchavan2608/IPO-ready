## Observed finding

Financial fields come from Chittorgarh HTML tables. Total income is preferred over revenue. Unknown financial scale defaults to crore. Identity checks accept some missing-date cases and include a weaker name-similarity route when month/year match.

## Review basis / method

Read fin_scale, verify, parse and main in cg_scrape.py. No scraper run.

## Learning / interpretation

This pipeline is an aggregator-data reference, not a direct prospectus parser.
