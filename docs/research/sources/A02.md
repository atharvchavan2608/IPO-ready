## Observed finding

Included rules are rescaled within categories. A category with no included points receives 50. Overall confidence uses weighted coverage thresholds, not measured prediction accuracy.

## Review basis / method

Static review of score_all, Rubric and selected rubric rules. Score function not executed.

## Learning / interpretation

Transparent arithmetic does not establish calibrated financial strength or reliable probabilities.

## Potential project use

Display coverage separately from score. Withhold unsupported category conclusions. Label confidence by its actual meaning.

## Limitations / transfer risks

No empirical calibration was evaluated. Different missing-rule patterns can change score comparability.
