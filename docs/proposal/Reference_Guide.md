# How the references inform IPO-Ready

The proposal's eight references cover the financial method, product presentation, document processing and primary data. These are design influences and supporting resources, not evidence that the proposed application has been validated.

| Proposal reference | Contribution to the project idea | Research register |
|---|---|---|
| 1. Piotroski (2000) | Financial strength can be examined through explicit accounting indicators. Supports showing profitability, leverage and operating performance rather than relying on narrative alone. | R01 |
| 2. Purnanandam and Swaminathan (2004) | IPO offer valuation can be compared with industry-peer multiples. Supports treating peer selection and valuation as distinct analytical tasks. | R02 |
| 3. Damodaran's valuation resources | Provides a framework and learning materials for relative valuation, P/E and enterprise-value multiples. Supports explicit choice of valuation method and denominator. | M01 |
| 4. FinQA (2021) | Financial answers can be represented through traceable numerical operations. Supports retaining inputs, formulas and source evidence for calculated findings. | R04 |
| 5. TAT-QA (2021) | Financial reports require reasoning across tables and accompanying text. Supports retaining headings, explanatory notes, units and period context during extraction. | R05 |
| 6. Screener.in | Illustrates how investors navigate statements, ratios, peer comparisons and source documents. Supports the dashboard's organisation, without implying endorsement or licensed data access. | P01 |
| 7. Docling | An open-source document-processing reference with layout and table handling. Supports investigation of structured extraction; it has not been adopted or benchmarked in the current demo. | T02 |
| 8. Aether RHP (2022) | A primary example of the financial statements and prospectus disclosures the project needs to analyse. Informed the observation schema and concrete financial definitions. | B01-B06 |

For a professor discussion, a useful explanation is: "Financial-analysis research helped us choose what to measure; valuation resources helped us frame company comparisons; existing research tools helped us organise the investor view; and document-analysis research helped us design how information and calculations remain connected to evidence."

Review limits remain in the source register: Piotroski selected methodology sections; IPO valuation publisher abstract; Damodaran resource index; FinQA abstract/repository overview; TAT-QA abstract; Screener public company page; Docling README; and selected Aether prospectus sections. Do not describe all sources as fully read or reproduced.

Bibliographic metadata and relevant public pages were checked again on 2026-10-22. FinQA and TAT-QA citations now use the official ACL Anthology records. Piotroski uses its journal DOI. The proposal contains the source URLs.
