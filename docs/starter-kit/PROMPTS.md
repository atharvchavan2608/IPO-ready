# IPO-Ready V2 prompts

Open the repository in a fresh coding session. Use **Kickoff** once to begin V2 and **Continue** to resume it. The agent can complete the requested scope in one run. **Independent review** and **Repair** are also available when requested separately. Keep new owner feedback in [steering](steering.md).

## 1. Kickoff

> Read `AGENTS.md` and the linked V2 requirements. Follow the first-session instructions, create the to-do list and run log, and work through the requested upgrade and verification autonomously.

## 2. Continue

> Read `AGENTS.md`, steering, the working state and run log. Complete and verify the requested scope autonomously. Choose the task order and group related work as needed. If something is blocked, continue with all work you can complete and record the blocker in the handoff.

## 3. Independent review

> Act as the founder's independent fintech product and analytics reviewer. Read `AGENTS.md`, follow its review instructions and record your findings in `docs/starter-kit/REVIEW.md`.

## 4. Repair

> Read `AGENTS.md` and `docs/starter-kit/REVIEW.md`. Follow the repair instructions and record the results.
