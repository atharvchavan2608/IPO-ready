# IPO-Ready proof of concept

Python analytics is the core. This local demo uses a curated historical Aether research dataset, not live market information or automatic extraction.

For a professor demonstration without starting a server, open [the self-contained demo](../outputs/poc/IPO_Ready_Demo.html). Its five selectable reports are generated by the Python engine, then packaged into HTML. The browser switches between precomputed results; it does not execute Python itself. Regenerate with `python scripts/build_demo_snapshot.py`.

From the project root, with Python 3.10 or newer:

```powershell
python app/main.py
```

Open http://127.0.0.1:8765. Stop with Ctrl+C. No API key or extra packages are required for the web demo. The pandas analysis notebook requires pandas.

Features: five period choices, 22 raw metrics, evidence links, annual revenue trend, Python ratios and four checks, known disclosure flags, JSON export, print report and transparent deterministic workflow trace. Inputs retain original units and are drawn from `research/aether_reconciliation/pilot_data.json`.

Validation:

```powershell
python -m unittest discover -s tests -v
```

Not implemented: live model decisions, automated extraction, new document upload, peer selection, scoring, valuation, authentication or multi-user deployment. The application is a local proof of concept. Review flags are generated from known pilot issues and simple rules; the app has not rediscovered the source discrepancies autonomously.
